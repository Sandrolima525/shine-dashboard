# Shine Dashboard

Crie um SaaS para gerenciamento de Lava Jato. Primeiro, configure as tabelas necessárias no Supabase para o funcionamento do sistema. Preciso de uma tabela de clientes (nome, telefone), uma tabela de veiculos vinculada aos clientes (placa, modelo, marca, cor) e uma tabela de ordens_servico (veiculo_id, tipo_de_lavagem, valor, status da lavagem como 'Na Fila', 'Lavando', 'Pronto' ou 'Entregue', e data).

Depois de estruturar o banco, crie um Dashboard moderno para o dono do lava jato visualizar os carros que estão lavando hoje, um botão para iniciar uma nova ordem de serviço e uma página para listar os clientes e seus veículos."
